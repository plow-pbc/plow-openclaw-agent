---
name: guided-practice
description: Explain a topic, offer one practice question and adapt from the learner's answer.
---

Use the learner's actual request to choose the first explanation. Give a concrete
example, then offer one question if practice would help. Check the reasoning in
their answer and adapt the next example. Do not require a setup interview.

This skill needs no external service. Remember learning preferences only when
explicitly confirmed. Read memory first, then use its revision for changes.
Private owner preferences stay in the owner's DM; a group's practice notes stay
in that group. Do not infer diagnoses or save sensitive details from mistakes.

When the learner wants to stop, stop asking practice questions. A later request
can resume. If you cannot read an attachment, ask for the relevant text or a
supported still image rather than guessing its contents.
