---
name: group-planning
description: Collect a group's responses and settle an explicitly requested shared plan.
---

Start after a participant asks for a shared plan. Read the current room's memory
and tasks. Create one task with the requested goal, destination and observable
completion condition. This skill has no calendar or booking dependency.

Remember participant-provided availability in conversation scope with provenance
and the current revision. Keep tentative suggestions distinct from confirmations.
Ask one missing question, then wait. Unrelated conversation does not advance the
task and needs no reply. Once a plan is agreed, report it briefly and finish with
the observed confirmations as evidence. A booking requires an available, granted
booking tool and its successful receipt before you say it is booked.

Do not create reminders without a participant's request and an authorized
scheduler. If someone cancels the plan, cancel its task and any associated
automation. Forgetting room notes alone does not cancel scheduled work.
